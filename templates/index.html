Ingested DDoS Vectors

The system classifies incoming packets into discrete DDoS threat patterns

L4 Transport
SYN Flood

Exploits the TCP 3-Way Handshake by saturating the victim server with SYN packets. The attacker leaves connections "half-open" by ignoring subsequent SYN-ACK signals.

  • Extremely high PPS
  • Low packet size (~64B)
  • Massive IP flow count
L4 Transport
UDP Flood

Floods random ports on the victim host with stateless User Datagram Protocol packets. Forces the victim OS to search for listening apps and reply with ICMP "Destination Unreachable".

  • High Bandwidth (BPS)
  • Large packet size (~1250B)
  • Moderate attacker IP count
L7 Application
HTTP Get Flood

Mimics legitimate user requests using a distributed botnet to send HTTP GET/POST queries. Exhausts web server application resources (CPU/RAM) through database fetches.

  • Moderate PPS and BPS
  • Extremely dense flow counts
  • Identified via high IP entropy
L7 Reflection
DNS Amplification

A reflection attack where spoofed queries are sent to open DNS servers. The request has the victim's return IP, triggering amplified DNS replies back to the target.

  • Maximized bytes-per-packet
  • Extremely high BPS
  • Few distinct source IPs

Feature Extraction Engine

To enable reliable real-time classification, the system extracts high-order mathematical features from raw network logging windows. Binary packets are mapped into 5 core features:

Feature Name Formula / Extraction Method Target Behavior
pps_mean Mean packets per 5-second sampling epoch Elevated on all volumetric attacks
pps_std Standard deviation of packet frequency windows High variance on bursty attacks
ip_entropy Shannon entropy log mapping of source IPs Peaks on highly spoofed botnets (SYN/HTTP)
flow_density Packets Ingested / Active Session Flows Signals dense streams from few sources
bytes_per_packet Bytes Ingested / Packets Ingested Flags DNS amplification vs small-packet SYN floods

Multi-Model Classification Suite

Rather than relying on one classifier, the console benchmarks and tracks four algorithms simultaneously. The operator can choose the active prediction driver depending on real-time speeds:

Random Forest
High-accuracy ensemble of decision trees. Excellent for robust non-linear boundaries. Default model.
Decision Tree
Extremely fast execution. Builds hierarchical rule sets. Easily explainable and highly efficient.
Logistic Regression
Linear probabilistic model. Superb baseline indicator, very lightweight, fast fitting speed.
SVM Classifier
Finds the optimal separating hyperplane in high dimensions. Highly generalized and robust.
